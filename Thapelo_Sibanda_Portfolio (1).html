Independent portfolio project · SQL Server

End-to-end SQL
data warehouse

Designed and built a SQL Server data warehouse using six sample CRM and ERP source files and a Bronze → Silver → Gold architecture. T-SQL stored procedures load the source CSVs into Bronze tables, transform and standardise records in Silver, and expose customer and product dimensions plus a sales fact view in a Gold-layer star schema.
